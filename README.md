# The Last Lighthouse

A first-person action RPG about restoring a lighthouse settlement in a drowned
world. Every trip into danger builds somewhere worth coming home to.

- **Engine:** Three.js 0.186 · TypeScript (strict) · Vite
- **Art:** Blender → glTF (`.glb`), generated by scripts in `tools/blender/build`
- **Status:** Chapter 1 is playable start to finish. See
  [docs/MILESTONES.md](docs/MILESTONES.md) for what's done and what's left.
- **Play:** https://ycgnem.github.io/last-lighthouse/ (Chrome or Edge)

## Run

```bash
npm install
```

```bash
npm run dev
```

Open http://localhost:5173 and click to start.

## Controls

| | |
|---|---|
| WASD | move |
| Mouse | look |
| Space | jump |
| Shift | dash (brief invulnerability) |
| LMB | fire the bolt-caster (not at home) |
| E | interact, talk, continue dialogue; hold to gather; press on the splash to land a fish |
| F | eat the selected food |
| Z | cycle food |
| Tab | keeper's journal: satchel, skills, lighthouse, settings |
| Esc | pause (and release the mouse); closes menus |
| T | *(dev)* skip the tide forward 60 s |

Some browsers, including embedded previews like the Claude app's browser pane,
won't capture the mouse. The game still starts there: move the mouse to look,
and hold it near the left or right edge to keep turning. Chrome and Edge capture
the mouse normally.

## The chapter

1. **Lantern's Rest.** Talk to Maren by the lighthouse door. The hearth, storage
   chest, forge and dock are your stations; the lighthouse lamp shows what the next
   upgrade needs.
2. **Gullwash Shore** (cliff path, or the boat once the dock's mended).
   Driftwood, scrap, kelp and sea glass; silverfin off the jetty; crabs on the
   flats. The tide floods the flats every ~9 minutes, and a horn warns you a
   minute ahead.
3. Cook, rekindle the forge, mend the dock, restore the lamp. The beam reaches
   the **Wreck of the Meridian**.
4. **The wreck.** At low tide go in through the hull breach; at high tide cross the
   floating cargo to the fallen mast. Take the Drowned Lens from the chart room
   and get out alive.
5. Focus the light. The beam finds **Saltmere Beacon**. Cross the causeway, face
   the Wreck Guardian (jump or dash its chain sweep, then shoot the exposed heart)
   and carry the Ember to the beacon's lamp.

Defeat isn't the end: the tide carries you home, and you lose 40% of what you
were carrying (never what's in the chest, never key items).

## Commands

| | |
|---|---|
| `npm run dev` | dev server at http://localhost:5173 |
| `npm run check` | typecheck |
| `npm test` | unit tests, content validation (softlock check), level marker checks |
| `npm run build` | typecheck + production build |
| `npm run build:art` | rebuild all Blender art headless (`-- wreck beacon` for some) |
| `npm run export:models` | export hand-edited `.blend` files to `.glb` |

Every push to `main` runs the tests and the build, then publishes `dist/` to
GitHub Pages (`.github/workflows/deploy.yml`).

## Known limitations

- Art is chunky low-poly from build scripts; water is a simple wave plane; no rain,
  bloom or music yet.
- Upgrades swap the world instantly (no camera cinematics yet).
- Sounds are synthesised in the browser; there are no recorded audio files.
- The Lantern Flare (Q), key rebinding UI and accessibility options aren't built.
