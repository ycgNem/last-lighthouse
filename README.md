# The Last Lighthouse

A first-person action RPG about restoring a lighthouse settlement in a drowned
world. The sea brings the drowned world's wreckage into the cove; you hook it out
and rebuild the place plot by plot. Every trip into danger builds somewhere worth
coming home to.

- **Engine:** Three.js 0.186 · TypeScript (strict) · Vite
- **Art:** Blender → glTF (`.glb`), generated by scripts in `tools/blender/build`
- **Status:** Chapter 1 is playable start to finish. See
  [docs/MILESTONES.md](docs/MILESTONES.md) for what's done and what's left.
- **Play:** https://ycgnem.github.io/last-lighthouse/ (Chrome or Edge)

## Run

```bash
npm install
```

```bash
npm run dev
```

Open http://localhost:5173 and click to start.

## Controls

| | |
|---|---|
| WASD | move |
| Mouse | look |
| Space | jump |
| Shift | dash (brief invulnerability) |
| LMB | fire the bolt-caster; at home, throw the hook |
| RMB | throw the salvage hook at what you're aiming at |
| Q | Lantern Flare: staggers enemies in front of you, burns away Gloom |
| E | interact, open, talk, hand materials in at a plot, continue dialogue; press on the splash to land a fish |
| B | build mode at home: LMB places, RMB picks up (full refund), R turns, wheel or 1–9 chooses |
| F | eat the selected food |
| Z | cycle food |
| Tab | keeper's journal: satchel, skills, lighthouse, settings (rebind keys, accessibility) |
| Esc | pause (and release the mouse); closes menus |
| T | *(dev)* skip the tide forward 60 s |

Some browsers, including embedded previews like the Claude app's browser pane,
won't capture the mouse. The game still starts there: move the mouse to look,
and hold it near the left or right edge to keep turning. Chrome and Edge capture
the mouse normally.

## The chapter

A new game opens with a short prologue: the sea rose, the great lights hold back
the Gloom, and this one is failing. You're its new keeper. The objective panel
names where each material comes from, and the compass points the way to it, then
home.

1. **Lantern's Rest.** Talk to Maren by the lighthouse door, then go down to the
   cove. The tide brings drift in through the mouth (plank bundles, oil drums,
   kelp mats, bottles, logs, now and then a ship's crate): throw the hook (RMB)
   and reel it in. At low water the wreck field is bared: each pull tears a
   piece off. The tide turns every ~4½ minutes, and a horn warns you a minute
   ahead.
2. **Rebuild.** Every ruin has a board: press E to hand in whatever you have, and
   watch the building rise. The forge first (smithing, the Iron Hook), then the
   jetty (Tib and the boat), then the Marsh Cottage (Odile comes home). The net
   loft, the smokehouse and two more cottages are there when you want them, and
   build mode (B) turns what's left into lanterns, fences, benches and bunting.
3. Fish off the rocks, grill at the hearth, restore the lamp. The beam reaches
   the **Wreck of the Meridian**.
4. **The wreck.** At low tide go in through the hull breach; at high tide cross the
   floating cargo to the fallen mast. Take the Drowned Lens from the chart room
   and get out alive.
5. Focus the light. The beam finds **Saltmere Beacon**. Cross the causeway, face
   the Wreck Guardian (jump or dash its chain sweep, then shoot the exposed heart)
   and carry the Ember to the beacon's lamp.

Defeat isn't the end: the tide carries you home, and you lose 40% of what you
were carrying (never what's in the chest, never key items).

## Settings and accessibility

In the journal (Tab) → Settings: mouse sensitivity, field of view, volume,
screen shake, head bob, bloom and rain; **resolution** (Auto lowers it while the
GPU can't keep up and raises it again when it can, or pick a fixed scale); **rebind any key** (click it, press the
new one; Esc cancels, and a key already in use swaps over); **reduced motion** (no
shake, bob, sway, dash kick or flashes; a new save follows your system setting);
**high-contrast enemy shots** (pale cores with dark rims, so they don't rely on
colour); **sound captions** for horns, windups, chimes and roars, with the side
they came from.

## Commands

| | |
|---|---|
| `npm run dev` | dev server at http://localhost:5173 |
| `npm run check` | typecheck |
| `npm test` | unit tests, content validation (softlock check), level marker checks, the tide-trap sweep, the pacing simulation |
| `npm run build` | typecheck + production build |
| `npm run build:art` | rebuild all Blender art headless (`-- wreck beacon` for some) |
| `npm run export:models` | export hand-edited `.blend` files to `.glb` |

Every push to `main` runs the tests and the build, then publishes `dist/` to
GitHub Pages (`.github/workflows/deploy.yml`).

## Known limitations

- Art is stylised low-poly from build scripts, vertex-coloured, with no image
  textures. There's no music yet.
- The people at home are [Polyfork](https://polyfork.dev) characters loaded from
  Polyfork's CDN (their licence doesn't allow copying the files into this repo).
  Offline you get simple placeholder figures instead.
- Upgrades swap the world instantly (no camera cinematics yet).
- Sounds are synthesised in the browser; there are no recorded audio files.
- Balance is checked by simulation (`tests/economy.test.ts`), not yet by
  fresh-player playtests.
