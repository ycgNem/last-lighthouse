# Asset List — Chapter 1

Everything the slice needs. Tick when it's in the game. Models are generated by
`tools/blender/build/*.py` (see ART_PIPELINE.md); a missing model falls back to a
primitive placeholder of the same size. Tri budgets are targets, not hard limits.
